# 🛡️ Sentinel — AI-Assisted Hybrid Threat Intelligence Platform

**Sentinel** is an AI-assisted Hybrid Threat Intelligence platform designed to support analysts in identifying, prioritizing, and visualizing potentially coordinated or suspicious activity across heterogeneous intelligence signals.

The project demonstrates how **AI-assisted analytics, risk scoring, anomaly detection, sentiment analysis, and interactive data visualization** can be combined into a unified Threat Intelligence workflow.

> **Research / Portfolio Prototype**  
> Sentinel is a proof-of-concept system based on synthetic intelligence scenarios. It is designed for research, experimentation, and analyst-support demonstrations.

## 🎯 Objectives

Sentinel aims to help analysts:

- Identify potentially suspicious activity
- Prioritize high-risk intelligence records
- Detect anomalous engagement patterns
- Combine multiple threat indicators
- Explore sentiment and narrative signals
- Visualize relationships between accounts, narratives, and indicators
- Support human-led Threat Intelligence analysis

The platform follows an analyst-support philosophy:

```text
Intelligence Data
       ↓
Feature Extraction
       ↓
Risk & Anomaly Analysis
       ↓
AI-Assisted Prioritization
       ↓
Interactive Visualization
       ↓
Human Analyst Decision
